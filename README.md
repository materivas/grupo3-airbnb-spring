# grupo3-airbnb-spring

Aplicación copia de Airbnb, desarrollada por el Grupo 3 utilizando Java + Spring Boot en el backend. Proyecto de la
materia "Taller de Metodologías Ágiles".

## Set up

1. Clonar el repositorio
2. Instalar Java JDK 17
3. Instalar Maven
4. En la terminal del proyecto, correr el comando `mvn clean install` para descargar las dependencias
5. Instalar MySQLWorkbench (asegurarse que el puerto sea el 3306 y el usuario root)
6. CREATE DATABASE "airbnb_db" y ejecutar comando
7. Correr AirbnbApplication.java
8. Conectarse a localhost en el puerto 8080
   Listo!
